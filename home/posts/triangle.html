title = Triangle Systems ---

I'm starting a little group in North Carolina dedicated to software internals. I keep these kinds of meetups very independent, with minimal sponsorship if any, and free of vendor pitches, so that we can have particularly high quality talks and discussions. Welcome to students or developers interested in the following topics:

  • Compilers / Virtual Machines
  • Databases / Storage
  • Distributed Systems
  • Web Browsers
  • Operating Systems / Linux Kernel
  • Formal Methods / Verification / Testing
  • High Frequency Trading
  • High Performance Computing

If I can convince you to come, please sign up for the mailing list [here](https://forms.gle/CqoRr9GhTeH79vTX6). Early 2027 timeframe.
